# CONPLANOS GNSS V10.4

Aplicación Streamlit para corrección GNSS, generación de data, certificados, historial, mapa y efemérides.

## Integraciones V10.4

- Google Sheets: historial permanente.
- Google Drive: almacenamiento opcional de PDF/Word de certificados.
- Google Login: acceso mediante Google.
- Google Maps Embed: opcional; el mapa actual y los enlaces a Google Maps no dependen de esta API.

Consulta `MANUAL_CONEXIONES_V10_3.md` para realizar la configuración en el orden correcto.
