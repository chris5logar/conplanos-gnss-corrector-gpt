# Publicación V4 en Streamlit Community Cloud

Sube a GitHub:

```text
app.py
core.py
requirements.txt
README.md
.gitignore
.streamlit/config.toml
```

`requirements.txt` instala Streamlit, PyMuPDF y openpyxl para lectura de Excel.

En Streamlit Community Cloud selecciona:

- Repository: tu repositorio;
- Branch: `main`;
- Main file path: `app.py`.

La V4 mostrará dos pestañas:

- **Corrector GNSS**
- **Generador de data**

No subas datos de clientes ni credenciales al repositorio.
